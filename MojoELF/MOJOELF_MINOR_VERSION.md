# MOJOELF_MINOR_VERSION

The current minor version of the MojoELF headers.

## Header File

Defined in [<mojoelf.h>](https://github.com/icculus/mojoelf/blob/main/mojoelf.h)

## Syntax

```c
#define MOJOELF_MINOR_VERSION   0
```

## Remarks

If this were MojoELF version 3.2.1, this value would be 2.

## Version

This macro is available since MojoELF 1.0.0.
