# MOJOELF_MICRO_VERSION

The current micro (or patchlevel) version of the MojoELF headers.

## Header File

Defined in [<mojoelf.h>](https://github.com/icculus/mojoelf/blob/main/mojoelf.h)

## Syntax

```c
#define MOJOELF_MICRO_VERSION   9
```

## Remarks

If this were MojoELF version 3.2.1, this value would be 1.

## Version

This macro is available since MojoELF 1.0.0.
